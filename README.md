# UFCA-AVA-Lembretes-APP
Esta aplicação tem como objetivo apenas mostrar de forma clara e direta, as informações sobre os compromissos que o aluno tem em relação as disciplinas cursadas na plataforma Moodle.

- Desenvolvido em Java e sem dependencias, o que torna o app muito leve e com apenas 326Kb.
